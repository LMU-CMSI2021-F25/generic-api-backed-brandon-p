#  Random Cat Generator

### Overview
The Random Cat Generator is a simple React web app that fetches and displays random cat images using [The Cat API](https://thecatapi.com/). Users can click a button to load a new random cat photo each time. It demonstrates fetching data asynchronously and updating the React UI dynamically.

### Features
- Fetches live data from a public API (The Cat API)
- Displays cat images with responsive design
- Provides loading and error handling states
- Includes animated button and hover effects
- Uses Google Fonts and gradient background for modern aesthetics

### API Used
- **Name:** The Cat API  
- **Documentation:** [https://thecatapi.com/](https://thecatapi.com/)  
- **Purpose:** Provides random cat image URLs for testing or entertainment

### Technical Highlights
- Fully abstracted API call in `src/api.js`
- Asynchronous `fetch()` implementation with `async/await`
- Clean, modern responsive design using Flexbox & transitions
- Zero console errors or warnings in development
